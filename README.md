# 🚀 OmniAI Universal Multimodal Intelligence Workspace

**OmniAI** is an advanced AI orchestration workspace and multi-model router designed for high-performance conversational intelligence, live HTML/JS sandboxes, deep scientific research, and dual multimodal media generation (Image + Motion Video).

---

## ✨ Features

- ⚡ **Intelligent Auto-Router**: Automatically routes queries to the optimal LLM engine (**Claude 3.5 Sonnet**, **GPT-4o Pro**, **Gemini 1.5 Ultra**, **DeepSeek-V3**, **Groq LLaMA 3.3**).
- 🎨 **Dual Multimodal Studio**: Generates high-resolution AI Still Photos (**Flux.1 Pro**) AND 60fps Motion Video Loops (**Sora 2 Engine**) in parallel.
- 🧪 **Live Code & Visualizer Sandboxes**: Interactive execution sandboxes for HTML/JS web apps, Bloch sphere quantum simulators, molecular bond visualizers, and micrograd autograd DAG graphs.
- 📚 **NotebookLM Workspace Integration**: Index PDFs, text files, and web links directly into the conversation context window.
- 🔑 **Role-Based Access Control**: Built-in 1-Click Google Sign-In with Admin & Guest access modes.

---

## 🛠️ Quick Start

### 1. Run Locally
```bash
python server.py
```
Open `http://127.0.0.1:8088` in your browser.

### 2. Launch Full Cluster with Auto-Tunnel
```bash
python run_cluster.py
```
